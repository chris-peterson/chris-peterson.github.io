## Major releases

### <span data-fact="plugin-anchor">anchor 2.0</span>

<div class="b2-release b2-ship"><a class="b2-badge" href="https://chris-peterson.github.io/anchor/#/"><img src="https://chris-peterson.github.io/anchor/favicon.svg" alt="">anchor docs</a>
<ul class="b2-list">
  <li data-fact="anchor-revdiff"><span class="b2-brk">Breaking:</span> Diff reviews open in <a href="https://revdiff.com">revdiff</a>, where you annotate and give the verdict. <code>diff.tool</code> is ignored, and revdiff 1.14 or later is required.</li>
  <li data-fact="anchor-hunk-notes">A commit's review leaves a note on each hunk you would stop to ask about, and a re-review opens on only what changed since you last looked, with an answer to each of your notes.</li>
  <li data-fact="anchor-review-rounds"><code>/anchor:review</code> drafts a fix for each finding and works in rounds: you keep, edit, or drop each draft in revdiff.</li>
  <li data-fact="anchor-stacks">Stacked change requests: <code>/anchor:stack</code> draws and builds the stack, <code>/anchor:rebase</code> catches a branch up (cascading through a stack), and <code>/anchor:ready</code> takes a CR out of draft.</li>
  <li data-fact="anchor-amend"><code>/anchor:amend</code> folds your changes into the last commit, still tested and reviewed, and offers a new commit when HEAD can't be amended.</li>
</ul></div>

### <span data-fact="plugin-claudewatch">ClaudeWatch 1.0</span>

<div class="b2-release b2-guard"><a class="b2-badge" href="https://chris-peterson.github.io/ClaudeWatch/#/"><img src="https://chris-peterson.github.io/ClaudeWatch/favicon.svg" alt="">ClaudeWatch docs</a>
<ul class="b2-list">
  <li data-fact="cw-auto-mode"><span class="b2-brk">Breaking:</span> Claude Code settles most allows before any plugin is asked, so ClaudeWatch now only restricts: it asks or blocks. A block holds in every permission mode; in <code>auto</code>, an ask runs without a prompt unless the session is marked with <code>/ClaudeWatch:unattended</code>. <code>/ClaudeWatch:learn</code> no longer proposes allow rules.</li>
  <li data-fact="cw-fail-closed"><span class="b2-brk">Breaking:</span> The guard fails closed: when its hook can't run, every Bash, Write, and Edit call is blocked. <code>$(</code> inside double quotes counts as compound, so the heredoc commit shape is blocked; write the message to a file and run <code>git commit -F msg.txt</code>.</li>
  <li data-fact="cw-overrides">Rule changes made with <code>/ClaudeWatch:rules</code> survive upgrades. Edits made in the plugin's own folder need redoing with the skill.</li>
  <li data-fact="cw-unattended"><code>/ClaudeWatch:unattended</code> lets a session keep working while you are away. Nothing waits on a prompt nobody is there to answer.</li>
  <li data-fact="cw-rule-sets">New rule sets cover <code>pkill</code> and <code>killall</code>, <code>sudo</code>, running downloaded code, and commands with no undo (<code>terraform destroy</code>, <code>gh repo delete</code>, <code>npm unpublish</code>). The agent can't loosen the rules; a loosening change is printed for you to run.</li>
  <li data-fact="cw-ask-in-auto">Since Claude Code 2.1.284, a session with no configured mode starts in <code>auto</code>, where an <code>ask</code> runs without a prompt. Set <code>"permissions": { "defaultMode": "default" }</code> to get the prompts back.</li>
</ul></div>

## Other changes

<ul class="b2-list b2-other">
  <li data-fact="catalog-jobs">The catalog groups plugins by the job they help with, and the mark is a helm with one spoke per job.</li>
  <li data-fact="plugin-moor plugin-logbook">moor and logbook are archived. Diff review moved to revdiff, through anchor.</li>
  <li data-fact="beacon-tabs">Since <a href="https://github.com/chris-peterson/beacon/releases/tag/v2.21.0">beacon 2.21</a>, a tab shows why a session needs you: ❓ for a question, 🔒 for a permission, 👀 while an anchor review is open.</li>
  <li data-fact="cleat-tiering">cleat measures what a repo's agent instructions cost at launch and moves each piece to the cheapest place that still reaches the agent.</li>
  <li data-fact="plugin-events">Plugins react to each other: one announces what it did, and the others act on it. The <a href="https://chris-peterson.github.io/claude-marketplace/spec/events">events page</a> lists who announces what and who listens.</li>
</ul>
