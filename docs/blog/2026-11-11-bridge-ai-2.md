# bridge.ai 2.0

bridge.ai 2.0 adds four plugins (rig, fathom, masthead, and sonar), releases anchor 2.0 and ClaudeWatch 1.0, and archives moor and logbook.

## New plugins

- <img class="b2-icon" src="https://chris-peterson.github.io/rig/favicon.svg" alt="">**[rig](https://chris-peterson.github.io/rig/#/)** launches Claude Code with a named set of plugins, your local checkouts pinned in, and the sandbox on when you want it.
- <img class="b2-icon" src="https://chris-peterson.github.io/fathom/favicon.svg" alt="">**[fathom](https://chris-peterson.github.io/fathom/#/)** keeps the facts of a piece of work in one record and renders a document for each reader from it. Every figure in a document cites the fact it came from.
- <img class="b2-icon" src="https://chris-peterson.github.io/masthead/favicon.svg" alt="">**[masthead](https://chris-peterson.github.io/masthead/#/)** sets up a docs site for a repo with `/masthead:bootstrap`: home page, navigation, search, and a deploy that publishes on every push. docsify is the engine today.
- <img class="b2-icon" src="https://chris-peterson.github.io/sonar/favicon.svg" alt="">**[sonar](https://chris-peterson.github.io/sonar/#/)** finds something you saw somewhere. `/sonar:pulse` answers with the closest matches right away, keeps searching git history, sibling repos, and past sessions, and hands over the rest at your next prompt.

## <img class="b2-icon" src="https://chris-peterson.github.io/anchor/favicon.svg" alt="">anchor 2.0

- Diff reviews open in [revdiff](https://revdiff.com), where you annotate and give the verdict. Breaking: `diff.tool` is ignored, and revdiff 1.14 or later is required.
- Reviews carry notes on the hunks you would ask about, and a re-review shows only what changed since you last looked.
- `/anchor:review` drafts fixes in rounds, and you keep the ones you want.
- Stacked change requests: `/anchor:stack`, `/anchor:rebase`, and `/anchor:ready`.

## <img class="b2-icon" src="https://chris-peterson.github.io/ClaudeWatch/favicon.svg" alt="">ClaudeWatch 1.0

- ClaudeWatch is built for auto mode. Claude Code settles most allows before any plugin is asked, so ClaudeWatch now only restricts: it asks or blocks, and that holds in every permission mode. Breaking: `/ClaudeWatch:learn` no longer proposes allow rules.
- Rule changes made with `/ClaudeWatch:rules` survive upgrades. Edits made in the plugin's own folder need redoing with the skill.
- `/ClaudeWatch:unattended` lets a session keep working while you are away. Nothing waits on a prompt nobody is there to answer.
- New rule sets cover `pkill` and `killall`, `sudo`, running downloaded code, and commands with no undo (`terraform destroy`, `gh repo delete`, `npm unpublish`). The agent can't loosen the rules; a loosening change is printed for you to run.

## Other changes

- The catalog groups plugins by the job they help with, and the mark is a helm with one spoke per job.
- moor and logbook are archived. Diff review moved to revdiff, through anchor.
- beacon tabs show why a session needs you: ❓ for a question, 🔒 for a permission, 👀 while an anchor review is open.
- cleat measures what a repo's agent instructions cost at launch and moves each piece to the cheapest place that still reaches the agent.
- Plugins react to each other: one announces what it did, and the others act on it. The [events page](https://chris-peterson.github.io/claude-marketplace/spec/events) lists who announces what and who listens.

## What's Next

A rough direction, not a schedule:

- **Writing plugins.** shipyard grows a kit for plugins built around a CLI, help wiring one plugin to another's events, and a routine for keeping the suite tidy.
- **Docs that stay current.** masthead keeps a docs site in step with the code and publishes a feed. fathom renders a Slack-ready version of a document and checks claims against their sources.
- **Finding your way.** sonar takes over the link graph from cleat and reports files nothing links to. tack gets a daily focus agent: what to work on, and who is waiting on you.
- **Safer shells.** ClaudeWatch looks closer at risky command shapes and keeps secrets from reaching disk.
- **Landing work.** mate holds the line on failing tests and adds playbooks for a greenfield build, a debt sprint, and a cutover.
- **Instructions that pay their way.** cleat manages rules: write one, amend it, choose when it loads, and switch it off to see what it costs. It also routes docs between agents, maintainers, and end users. sextant steers work from the spec.
